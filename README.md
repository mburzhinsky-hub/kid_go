# КидГоу 🎈

**Выберите настроение — мы соберём ваш день.**

Mobile-first веб-приложение для родителей: не каталог детских мест, а персональный семейный планировщик.
Пользователь выбирает, кто идёт, сколько есть времени, настроение, бюджет и транспорт — и получает
готовое «приключение»: несколько мест рядом, время каждого шага, дорогу между ними, бюджет на семью,
возраст, подходит ли погода и почему это подходит именно этой семье.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:3000 — открывайте в мобильном режиме DevTools (375–430 px)
npm run build && npm start
npx tsx scripts/check-engine.ts   # санити-проверка рекомендаций (1 728 комбинаций)
```

Node 20+. Внешние сервисы не обязательны: данные — в mocked data layer, фото — с CDN Unsplash,
карта — бесплатные векторные тайлы OpenFreeMap (без ключа). Если тайлы недоступны, включается
иллюстрированная офлайн-карта.

## Что внутри

| Маршрут | Экран |
|---|---|
| `/` | Главная: категории, hero-карусель, «Что хочется сегодня?», готовые приключения, погода, популярное, афиша дня, подборка для ваших детей |
| `/search` | Поиск с разбором естественного языка («недалеко, побегать и потом поесть») |
| `/map` | Карта с фото-маркерами, раскладкой без наложений (+N), фильтрами и карточкой места снизу |
| `/adventures`, `/adventures/[slug]` | Готовые приключения и страница приключения с таймлайном, выбором времени старта и sticky «Поехали!» |
| `/places/[slug]` | Место: галерея, ключевые параметры, «Для родителей», **«Что сделать после?»**, отзывы |
| `/planner` → `/planner/results` | Генератор дня: 5 шагов (или фраза словами) → игривый лоадер → «Мы придумали вам субботу 💛» |
| `/day` | «Наш день»: маршрут, собранный через «Что потом?» (редактируемый) или сгенерированный (ссылкой можно поделиться) |
| `/favorites` | «Наши хотелки ❤️»: хотим сходить · сохранённые приключения · уже были, «собрать день из хотелок» |
| `/profile` | Профиль семьи: дети (имя, дата рождения/возраст, интересы), бюджет, транспорт, дальность |
| `/onboarding` | Знакомство и первый ребёнок |
| `/admin` | Минимальный кабинет контента (места, приключения, события) |
| `/api/places`, `/api/places/[slug]`, `/api/adventures`, `POST /api/plan` | Публичный API поверх того же слоя данных |

## Архитектура

```
src/
  app/                    маршруты (App Router, Next.js 16, React 19)
  components/             UI по доменам: home, cards, place, adventure, planner, map, profile, favorites, ui
  lib/
    types.ts              доменные модели: Place, Adventure, Event, Plan, PlannerInput…
    data/                 mocked data layer: 38 мест, 12 приключений, афиша; repository.ts — единая точка доступа
    recommend/engine.ts   recommendation layer: фильтры → скоринг → сборка комбинаций
    recommend/explain.ts  человекопонятные объяснения «почему вам подойдёт»
    recommend/nlu.ts      разбор естественного языка в фильтры
    plan.ts               расчёт маршрута: время, дорога, бюджет, возраст
    store.ts              состояние семьи (zustand + localStorage → в проде синхронизация с БД)
prisma/schema.prisma      схема PostgreSQL + PostGIS для production
```

### Recommendation engine (без LLM как источника истины)

1. **Фильтрация**: возраст всех детей, расстояние (по транспорту), погода, бюджет, часы работы в нужное окно.
2. **Скоринг**: `age×3 + weather×3 + distance×2 + interest×2 + rating + mood×4 + activity + personalization`.
3. **Сборка**: якорное место → ближайшее кафе (если хватает времени/просили поесть) → дополняющая точка
   (магазин игрушек, парк) с учётом бюджета, открытости и дистанции; дубликаты и однотипные дни отсекаются.
4. **Нет результата** → подсказки, какое ослабление условий даст хороший день.

AI-слой (`nlu.ts`, `explain.ts`) работает только поверх базы: превращает фразу в фильтры и формулирует
объяснения из фактов плана. Интерфейсы совместимы с LLM-провайдером (function calling), но места
он не придумывает.

### Design system

Снята с визуального референса: светлый тёплый фон `#FBFAF7`, белые карточки с мягкой тенью, радиусы 18–28 px,
фуксиевый primary `#FF2E88`, категориальная палитра (жёлтый/зелёный/розово-красный/фиолетовый/голубой/оранжевый),
крупные заголовки 24–32 px weight 800–850, пухлый разноцветный логотип, залитые иконки категорий.
Токены — в `src/app/globals.css` (`@theme`), категории/сценарии/интересы — в `src/lib/catalog.tsx`.

### Состояния

loading (скелетоны маршрутов), empty (иллюстрированные), error (`error.tsx`), no results (поиск, планировщик
с подсказками), offline (баннер + service worker + `offline.html`), geolocation denied (карта),
closed place (статус «Закрыто · откроется в…»), bad weather (дождевые приключения первыми, баннер «под крышей»),
нет фото (яркая иллюстрация вместо серого плейсхолдера), нет тайлов карты (иллюстрированная карта).

### Производительность и SEO

SSG для всех мест и приключений (`generateStaticParams`), ISR главной (30 мин), `next/image` с CDN-лоадером
(ресайз/AVIF/WebP на стороне CDN), lazy-загрузка, MapLibre подгружается динамически только на `/map`,
`optimizePackageImports` для иконок. Metadata, OpenGraph, JSON-LD (TouristAttraction/Museum/Restaurant, TouristTrip),
`sitemap.xml`, `robots.txt`, чистые slug'и (`/places/skazochny-les`, `/adventures/den-dinozavrov`). PWA: manifest,
иконки, service worker.

## Подключение production-инфраструктуры

- **БД**: `npm i -D prisma && npm i @prisma/client`, `DATABASE_URL`, `npx prisma migrate dev`; реализовать
  `DataRepository` через Prisma (гео-запросы — `ST_DWithin` по колонке `geom`). UI менять не нужно.
- **Auth**: Supabase Auth / Clerk — `Family.id = user.id`; `store.ts` синхронизирует детей, хотелки и сохранённые планы.
- **Storage**: фото мест в Supabase Storage / S3; поменять базу URL в `src/lib/image-loader.ts`.
- **Карта**: `NEXT_PUBLIC_MAP_STYLE_URL` — любой MapLibre-совместимый стиль (MapTiler, Mapbox и т.п.).
- **Погода**: заменить мок в `src/lib/weather.ts` на Open-Meteo / Яндекс.Погоду.
- **Аналитика/мониторинг**: `src/lib/analytics.ts` (PostHog), `src/app/error.tsx` — точка для Sentry.
- `NEXT_PUBLIC_SITE_URL` — домен для sitemap/OG.
